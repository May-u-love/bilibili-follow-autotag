# B站关注自动分组 (Bilibili Follow Auto-Tag)

一个 Chrome 扩展（Manifest V3）：**新关注的B站UP主自动归类到你指定的分组**，无需手动整理关注列表。

## ✨ 功能

- **实时捕获**：注入B站页面监听关注动作，点"关注"的瞬间自动归类
- **定时兜底**：后台定时扫描关注列表（1~60分钟可调），补漏处理离线期间的新关注
- **两级分类**：
  1. 先按 UP主名称 / 签名 / 官方认证描述 匹配关键词规则
  2. 判断不了时，自动拉取该UP主最近投稿标题做内容分析
  3. 仍无法判定 → 放入「其他与个人账号」（可配置为留在默认分组）
- **弹窗控制面板**：启停开关、检查频率、状态统计、实时归类日志
- **角标提示**：浏览器图标上显示今日自动分组数量

内置19个分组方案（游戏与电竞、知识科普与人文、数码科技与硬件、编程AI与软件工具、财经投资与商业、音乐与音乐人、影视与动漫、军事与国际时政、美食、生活旅行与纪实、搞笑与娱乐、视觉创作与时尚、健康与健身、教育与学习、萌宠动物、汽车与出行、德州扑克、官方媒体与品牌、其他与个人账号），分组缺失时扩展会自动创建。

## 📦 安装（开发者模式加载）

1. 下载本仓库（`Code` → `Download ZIP` 并解压，或 `git clone`）
2. 打开 Chrome，地址栏输入 `chrome://extensions`
3. 右上角开启 **开发者模式**
4. 点击 **加载已解压的扩展程序**，选择本仓库文件夹
5. 确保浏览器已登录B站，然后点工具栏中的扩展图标打开控制面板

> Edge 同样适用：`edge://extensions` → 开发者模式 → 加载解压扩展。

## ⚙️ 配置

| 配置项 | 位置 | 说明 |
|---|---|---|
| B站UID | `background.js` 顶部 `VMID` | 默认写死了一个UID，改成你自己的 |
| 分组方案 | `rules.js` 顶部 `GROUPS` | 与你B站账号里的分组名保持一致 |
| 分类关键词 | `rules.js` 的 `CERT_RULES` / `NAME_RULES` / `TITLE_RULES` | 按需增删正则规则 |

## 🔍 工作原理

```
关注动作（页面注入捕获）或定时扫描
        │
        ▼
阶段1：名称+签名+认证描述关键词匹配
        │ 未命中
        ▼
阶段2：拉取最近10条投稿标题（动态接口，免wbi签名）分析
        │ 未命中
        ▼
放入「其他与个人账号」/ 留在默认分组（可配置）
```

- 首次安装只**记录基线**（当前关注列表），不会改动已有分组；之后仅处理新关注
- 规则已在 779 个真实分组样本上验证：关键词阶段覆盖率 64%、判定精度约 83%，投稿标题兜底与人工判定一致性 24/25
- 所有接口调用使用浏览器内B站登录态，分组创建/移动/取关均走B站官方Web接口

## 📁 目录结构

```
├── manifest.json          # MV3 扩展清单
├── background.js          # 后台服务：扫描、分类、调用B站接口
├── rules.js               # 分类规则（可自定义关键词）
├── content/
│   ├── interceptor.js     # 页面主世界：捕获关注按钮动作
│   └── bridge.js          # 消息桥接
├── popup/                 # 控制面板（开关/设置/统计/日志）
└── icons/                 # 图标
```

## ⚠️ 注意事项

- B站**分组数量上限为 30 个**，超出时扩展会把无法归类的账号放入「其他与个人账号」
- 已注销账号无法移动分组（B站限制）
- B站接口有风控，扩展内置了请求间隔；请勿同时运行多个同类脚本
- 本项目仅供学习交流，请遵守B站用户协议
